# NekoNekoNin · 天使之魂增强版

在原版天使之魂基础上增强长期记忆、自动学习、会话隔离与纠正撤销，让重要信息可追溯、可恢复。

版本：`1.6.16+timely.4` · 许可：[GPL-3.0（保留原许可）](LICENSE)

## 能做什么

- 在原版记忆能力上增强群聊/私聊隔离，按完整会话来源管理记忆范围。
- 支持重要信息优先整理、普通聊天累积整理与空闲整理。
- 增强事实纠正、学习记录与撤销，并同步全文与向量索引。

## 安装

在 AstrBot 的插件管理上传本插件发布 ZIP，或使用[本仓库地址](https://github.com/NekoNekoNin/astrbot_plugin_angel_memory)安装。内部插件名保持 `astrbot_plugin_angel_memory`，升级时沿用已有配置。元数据已绑定本仓库，更新时请核对版本与更新记录。

这是基于 kawayiYokami 原作的增强分支，保留原作者、源码声明和 GPL-3.0。需要配置可用的记忆整理模型；嵌入与重排为可选能力，不应把聊天模型 ID 填入不兼容的检索提供商。

## 设置

入口：**AstrBot → 插件 → NekoNekoNin · 天使之魂增强版 → 配置**。常用选项直接显示，适用时提供中文下拉标签、数值滑块、条件显示与高级折叠。完整选项见 [配置说明](docs/CONFIGURATION.md)。

## 聊天示例

- “自然表达自己的偏好，再在同一会话的新对话中询问。”
- “纠正先前记录的事实，并在学习记录中检查变更。”
- “撤销指定范围的错误学习，确认记忆恢复。”

## 使用边界

自动学习会筛选信息，不保证每句话都存入。整理触发时间不等于模型完成时间。相同人格不会自动合并不同群或私聊的记忆，旧共享映射保留兼容但不用于突破隔离。此版本不是上游原版或官方发行。
