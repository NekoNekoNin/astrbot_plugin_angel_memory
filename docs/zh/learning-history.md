# 学习记录与撤销

打开「天使的记忆」面板，在侧栏选择新增的「学习记录」。原有「记忆浏览」继续用于浏览现有记忆；「学习记录」用于查看启用本功能后每次新增、修正或合并的来源和前后内容。

通过「来源范围」筛选群聊或私聊的精确记忆范围，展开「查看来源与变更」可核对会话、原文节选和记忆内容。没有保留的来源会明确显示未记录，不补造旧记录。

点击「撤销本次学习」后，先核对记录、范围和将恢复的条数，再勾选确认并执行。如果相关记忆后来已被修改、合并或删除，系统会拒绝撤销并提示刷新，保留当前内容。

「已撤销 · 待同步」表示记忆内容已经恢复，但检索索引尚未同步。查看提示中的失败原因，点击该记录的「重试同步」。重复重试不会再次改写已恢复的记忆。

此页面沿用面板的管理员访问权限。历史记录可能含原文节选，应按记忆内容管理访问权限。
