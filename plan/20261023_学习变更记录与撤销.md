# 学习变更记录与撤销

用户在已提出的功能选项中选择了“1 和 6”，本计划落实其中第 6 项。

1. 在两种记忆运行时共用的中央 SQLite 数据源内，为新学习的新增、纠正与合并记录原子审计；保留作用域、真实来源、变更前后与时间，不回填历史来源。
2. 撤销只作用于单条学习。事务内核对所有涉及记忆的当前版本；若已被后续修改则拒绝，不覆盖新信息。重复撤销保持幂等。
3. 撤销后同步文字和向量检索索引；索引失败明确显示待同步，并可重复请求重试，不删除用户笔记或原始文件。
4. 扩展已有记忆面板的学习记录页面，提供范围筛选、来源和前后对比、撤销确认及冲突说明。
5. 通过临时数据库和实际存储接口验证隔离、纠正/合并恢复、冲突、幂等及失败回滚。实际部署环境为 Windows AstrBot 桌面版，测试使用相同 Python 环境，不使用已不适用的 Docker 命令。

计划等待用户生产环境测试后再归档。

开发验证（2026-10-24）：使用 Windows 桌面版同源 Python、临时 SQLite、真实 Tantivy 和 FAISS/SQLite 向量索引，65 项学习记录、纠正、合并、撤销、隔离及退役回归通过；反思来源身份测试单独执行 3 项通过。覆盖并发来源隔离、数据库失败原子回滚、撤销冲突与幂等、空嵌入和无文案超时的待同步状态，以及索引异步期间的新修改重读。未读取或修改生产记忆。
